# Solfège — prototype

Page d'essai : une partition dessinée par le moteur de rendu de Scorsaire (leçon et jeu de lecture de notes), avec lecture sonore.

Ce dépôt ne contient que l'application construite (GPLv3+, issue de Scorsaire). Les sons (SoundFonts) sont chargés depuis https://letournedosrossini.github.io/scorsaire-lecteur/.
